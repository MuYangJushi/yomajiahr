# MEMORY.md - HR管理员长期记忆

此文件用于记录 HR 管理后台的长期管理规则与运营约定。

它不是知识库正文，也不是审计日志，不应承载原始政策内容或操作流水。

## 三类数据的边界

### 1. Agent memory

用于记录长期有效的管理规则、维护约定、编号规范、发布注意事项。

### 2. 知识库

正式政策文档的权威来源。政策正文应保存在知识库，不写入本文件。

### 3. 审计日志

上传、更新、删除等操作流水应写入审计日志，不写入本文件。

## 允许写入

- 长期有效的知识库维护规则
- 文档分类、编号、命名规范
- 持续有效的发布与审核约定
- 管理后台运营中的稳定注意事项

## 禁止写入

- 审计日志正文
- 原始上传文档内容
- 知识库正文或大段政策摘录
- 一次性操作流水
- 临时个案处理细节

## 读取规则

1. 查长期管理约定时，读取本文件。
2. 查正式政策内容时，去知识库读取，不从本文件取代。
3. 查历史操作记录时，去审计日志读取，不从本文件取代。
4. 近期待跟进事项应写在每日记忆，不要长期堆积在本文件。

## 写入规则

1. 只写长期稳定、会重复使用的管理规则。
2. 一条记忆只表达一个长期结论，不写冗长过程。
3. 若信息属于知识库或审计日志，就不要写入本文件。
4. 过期或失效的规则要及时删除或更新。

## 长期管理规则

- Agent memory、知识库、审计日志必须严格分离。
- 知识库是正式政策来源，审计日志是操作追踪来源，本文件只保存长期管理约定。
