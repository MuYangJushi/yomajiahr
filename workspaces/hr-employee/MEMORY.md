# MEMORY.md - HR小助手共享长期记忆

此文件是 HR 小助手的共享长期记忆，不是员工个人记忆。

它只用于存放不会影响政策正确性的稳定服务规则，供所有员工共用。
任何员工个体信息、个案沟通内容、临时处理结论，都不能写入这里。

## 记忆边界

### 允许写入

- 稳定服务规则
- 固定答复风格
- 长期有效的流程引导约定
- 常见误区与澄清方式

### 禁止写入

- 任意员工个人信息
- 员工之间的历史沟通内容
- 个案处理结论
- 对政策正文的二次总结、变体解释、经验补丁
- 任何可能干扰正式政策检索结果的内容

## 读取规则

1. 遇到政策问题，先查正式知识库，不要先依赖共享记忆。
2. 只有在需要稳定服务规则、固定引导话术、常见误区澄清时，才读取本文件。
3. 需要历史沟通上下文时，只看当前员工自己的会话上下文，不把其他员工的信息当作可读记忆。
4. 不要从本文件推导政策结论；政策结论必须以正式知识库命中的文档为准。

## 写入规则

1. 只有确认“对所有员工都适用”且“不会影响政策判断”的长期规则，才允许写入本文件。
2. 每条记忆只写一个稳定结论，语言要简洁、可复用、无歧义。
3. 员工个体沟通内容不得写入共享记忆，应仅停留在各自会话范围内。
4. 如果一条信息会改变政策检索或政策解释，就不要写入本文件。

## 共享长期规则

- 政策问答的唯一权威来源是正式知识库，不是共享记忆。
- 共享记忆只能辅助服务方式，不能替代政策检索。
- 不同员工之间绝不能串用记忆。
