# 路由规则详细配置

## 意图分类器

全员 Agent 使用基于关键词 + 语义理解的意图分类。以下为各意图的详细匹配规则。

## 政策问答意图

### 高置信度关键词（直接触发）

- 制度、政策、规定、规章、办法、条例
- 年假、病假、事假、婚假、产假、陪产假、丧假
- 社保、公积金、五险一金、医保
- 福利、补贴、津贴
- 考勤规则、加班规定、迟到、早退

### 中置信度模式（结合上下文判断）

- "...怎么算"、"...怎么规定的"、"...是多少"
- "公司有没有...规定"
- "请问...政策"

### 示例

| 用户消息               | 意图     | 置信度 |
| ---------------------- | -------- | ------ |
| "年假怎么算？"         | 政策问答 | 高     |
| "病假需要什么材料？"   | 政策问答 | 高     |
| "公司有没有加班补贴？" | 政策问答 | 中     |
| "社保缴纳比例是多少？" | 政策问答 | 高     |

## 入离职意图（Phase 2）

### 关键词

- 入职、报到、入职流程、入职材料
- 离职、辞职、离职交接、离职证明
- 转正、试用期、转正评估

## 排班考勤意图（Phase 2）

### 关键词

- 请假、调班、换班、排班表
- 打卡、签到、签退
- 加班申请、出差申请
- 考勤异常、漏打卡

### 区分政策问答 vs 排班考勤

- "请假需要什么材料？" → 政策问答（问规则）
- "我要请 3 天年假" → 排班考勤（要操作）
- "加班怎么算工资？" → 政策问答（问规则）
- "提交加班申请" → 排班考勤（要操作）

**判断原则**：问"是什么/怎么规定"→ 政策问答；要"做某事/申请/提交"→ 排班考勤。

## sessions_spawn 参数

```jsonc
{
  "task": "<用户问题原文>",
  "label": "政策问答",
  "agentId": "hr-policy-rag",
  "runTimeoutSeconds": 120,
}
```

## 错误处理

| 场景                    | 处理                                     |
| ----------------------- | ---------------------------------------- |
| Sub-agent spawn 失败    | 回复"系统暂时繁忙，请稍后重试"           |
| Sub-agent 超时          | 回复"查询超时，请缩短问题范围后重试"     |
| Sub-agent announce 为空 | 回复"未获取到结果，请联系 HR 同事"       |
| 意图不明确              | 回复"您的问题涉及多个模块，请进一步描述" |
