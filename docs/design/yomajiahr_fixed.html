02 — 核心功能模块
五大 Agent，覆盖 HR 全链路

每个 Agent 具有独立的 System Prompt、工具权限和错误恢复策略。通过路由 Agent 实现意图识别与任务分发。

🧑‍💼
招聘助手 Agent
端到端覆盖招聘全流程，从 JD 生成到 Offer 审批，大幅降低招聘周期。
  • 基于 JD 自动筛选简历，多维度加权打分（技能匹配度、经验相关性、文化契合度）
  • 根据岗位职级 + 候选人背景自动生成结构化面试题库
  • 自动发送面试邀约，支持候选人自助选择时间段
  • 汇总多轮面试官反馈，生成录用/淘汰建议报告（含薪资区间参考）
  • 关键节点（发 Offer、薪资谈判）强制触发人工审批
📋
入职/离职流程 Agent
流程自动化引擎，跨部门协同零延迟。
  • 自动生成个性化 Onboarding Checklist（按岗位、部门、职级定制）
  • 触发跨部门并行任务：IT 开账号 → 财务配薪资 → 行政寄设备
  • 离职流程自动推进，实时监控权限撤销进度
  • 试用期到期自动提醒，配合绩效数据生成转正建议
📄
政策问答 Agent
RAG 驱动，回答有据可查。
  • 接入公司规章制度、假期政策、薪酬福利、社保公积金文档
  • 回答附来源页码与文档版本号，支持溯源审计
  • 多轮对话理解上下文（如：先问年假天数 → 追问跨年结转规则）
  • 未命中知识库时自动转人工，避免模型幻觉
📊
数据分析 Agent
用自然语言驱动人力数据洞察。
  • 人员流失率趋势分析，支持按部门/职级/司龄切片
  • 招聘漏斗分析：投递 → 筛选 → 面试 → Offer → 入职全链路转化率
  • 部门人效对比报告（人均产出、加班时长、离职率综合评分）
  • 自动生成可视化图表 + 文字解读 + 行动建议
🗓️
排班 & 考勤助手
智能排班，异常预警。
  • 基于历史数据 + 员工偏好 + 业务峰谷自动生成排班方案
  • 异常考勤模式识别（连续迟到、频繁请假聚集等预警）
  • 对接钉钉/飞书考勤 API，数据实时同步
  • 加班时长超标自动提醒（合规风控）
03 — Agent 编排策略
路由分发 + 多级回退机制

路由 Agent 作为统一入口，基于意图识别将请求分发至专业 Agent。新增置信度阈值与回退策略，避免误路由。

1

用户输入

来自 Web Portal / 企业微信 / 钉钉等渠道的自然语言请求。

2

路由 Agent — 意图识别与分类

基于语义理解判断意图类别，输出置信度分数。置信度 < 0.7 时触发澄清追问，避免误路由。

招聘相关 → 招聘 Agent政策查询 → RAG Agent数据分析 → 分析 Agent流程操作 → 流程 Agent排班考勤 → 考勤 Agent
3

专业 Agent 执行

调用工具完成任务。涉及敏感操作时进入人工确认节点，30分钟超时自动升级。

4

结果返回 & 日志记录

结构化结果返回前端渲染，全量操作日志写入审计表。失败时触发重试或降级通知。

04 — MCP 工具集成
标准化工具层，即插即用

通过 MCP 协议统一封装外部系统接口，每个工具定义明确的输入输出 Schema，Agent 可自主决定何时调用。

工具 用途 权限要求
hris_api 员工档案、组织架构、岗位信息的读取与更新 HR 管理员
recruit_platform 对接猎聘 / Boss直聘 / 拉勾，拉取简历、同步候选人状态 招聘专员+
calendar_mail 企业邮件发送、日历事件创建、面试会议室预定 基础权限
knowledge_rag 向量检索公司政策文档、FAQ 知识库 全员可用
data_warehouse SQL 查询人员数据，生成聚合统计与图表 分析师+
approval_engine 发起 / 查询审批流（Offer、调薪、离职） 按流程角色

优化点：新增 approval_engine 工具，将审批流从“人工确认节点”升级为标准化审批引擎，支持多级审批、并行会签、超时自动升级。每个工具新增权限要求字段，配合权限网关实现最小权限原则。

05 — Prompt 工程
三大核心原则

每个 Agent 的 System Prompt 遵循一致的设计原则，确保行为可控、输出可预期。

🎯 角色边界隔离

每个 Agent 拥有独立 System Prompt，明确定义其能力范围、可调用工具列表、输出格式约束。禁止 Agent 越界操作。

🔒 人机协作节点

关键决策（Offer 发放、薪资调整、绩效评定）强制进入人工审批。AI 提供建议与数据支撑，但不自主执行。

🛡️ 分级数据访问

Prompt 层内嵌权限校验指令：普通员工仅可查个人信息，HR 可查团队数据，管理层可查全局数据。薪资绩效需额外鉴权。

06 — 数据安全
四层纵深防御

HR 数据高度敏感，安全设计贯穿基础设施、数据传输、模型调用、操作审计四个层面。

基础设施隔离

私有化部署或企业专属 API Key，模型推理不经过公共云。VPC 网络隔离，数据不出域。

数据脱敏

PII 信息（身份证号、银行卡号、手机号）在送入模型前自动脱敏，推理完成后回填。支持自定义脱敏规则。

操作审计

全量操作日志记录（who/when/what/result），支持合规审计与事后追溯。关键操作实时告警。

双重确认机制

删除员工档案、发放 Offer、批量薪资调整等高风险操作需二次身份验证 + 审批通过后方可执行。

07 — 落地路径
三阶段渐进式落地

先从风险最低、价值最明显的场景切入，逐步扩展到核心流程和数据智能。

第一阶段 · 1–2 个月

快速验证：政策问答上线

RAG 问答机器人是落地门槛最低、员工感知最强的场景。接入 3–5 份核心政策文档即可上线，快速验证技术可行性与用户接受度。

知识库搭建问答准确率 > 90%用户反馈闭环
第二阶段 · 2–4 个月

核心流程：招聘 + 入离职自动化

在验证用户信任度后，接入招聘筛选与入职流程自动化。此阶段需要与 HRIS、招聘平台完成 API 对接，建立人机协作审批流。

简历筛选面试安排Onboarding 自动化审批引擎上线
第三阶段 · 4–6 个月

数据智能：分析 + 预测性洞察

数据积累到一定量级后，上线数据分析 Agent 与排班考勤助手。引入预测模型（离职风险预测、招聘需求预估）实现从“响应式”到“前瞻式”HR 的跃迁。

离职风险预测人效仪表盘智能排班招聘漏斗看板
